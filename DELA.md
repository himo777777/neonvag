## 4. Reddit (r/WebGames, r/playmygame, r/IndieGaming)

**Titel:** I made a one-touch neon game that runs in a single HTML file — no download, no ads

> Hold to rise, release to dive. That's the whole control scheme.
>
> There's a daily track that's the same for everyone, 12 levels, and an endless mode.
> The music is generated in real time — there are no audio files in the game at all.
>
> The whole thing is one HTML file with no build step and no libraries. No ads, and
> no analytics unless you actively opt in.
>
> https://himo777777.github.io/neonvag/?ref=reddit
>
> Feedback welcome — especially on the difficulty curve, I've been tuning the first
> 30 seconds a lot.
